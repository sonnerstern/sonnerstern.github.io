# Üres Trónok – GitHub Pages webcsomag

## Fájlok
- `index.html`: kezdőlap
- `kampanyok.html`: kampányáttekintő
- `amerika-nelkul.html`, `kina-nelkul.html`, `oroszorszag-nelkul.html`, `nagy-britannia-nelkul.html`: kampány-aloldalak
- `alapokmany.html`: Alapokmány
- `szabalyok.html`: a játékrendszer bemutatása
- `kartyatar.html`: nyilvános kártyatár-ismertető
- `dekolonizacio.html`: kiegészítő modul
- `enciklopedia.html`: digitális tudástár
- `assets/style.css`: közös arculat

## Telepítés
1. Készíts biztonsági másolatot a jelenlegi repository-ról.
2. Töltsd fel a csomagban lévő fájlokat a repository gyökerébe; az `assets` mappát is tartsd meg.
3. A kezdőlap neve pontosan `index.html` legyen.
4. GitHubon ellenőrizd: Settings → Pages → Build and deployment.
5. A `CNAME` fájlt és a domain DNS-beállításait ne módosítsd, ha a jelenlegi domain működik.
6. Várd meg a Pages build befejezését, majd ellenőrizd a domaint és a mobilnézetet.

## Megjegyzések
- Statikus HTML/CSS, nincs szükség build eszközre vagy külső JavaScript-könyvtárra.
- A tartalom magyar nyelvű és mobilbarát.
- A dátumok szándékosan nincsenek véglegesítve, mert az alternatív történeti kronológia korábbi változatai eltértek.
- A pontos játékszabályok és kártyahatások fejlesztés alatt álló munkaváltozatként vannak jelölve.
- Titkos célok, kézben tartott lapok és bizalmas játékosi információk nincsenek közzétéve.
